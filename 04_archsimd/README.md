# Архитектурный SIMD в Go 1.27

Одинаковый внешний API: `SliceContainsInt8`, `SliceContainsInt32`, `SliceContainsInt64`.

| Режим | Реализация |
|---|---|
| `amd64`, эксперимент включён, есть AVX2 | 256 бит: 32 × int8, 8 × int32, 4 × int64 |
| `amd64`, без AVX2 | `slices.Contains` |
| `arm64`, эксперимент включён | Neon 128 бит: 16 × int8, 4 × int32, 2 × int64 |
| Эксперимент выключен или другая архитектура | `slices.Contains` |

На amd64 маска сравнения сводится через `ToBits()`. На arm64 такого метода у этих
масок нет: преобразуем маску в целые числа (0 / −1), для int8/int32 используем
`ReduceMin() != 0`. `ReduceMax()` здесь было бы ошибкой: одна нулевая позиция
скрывала бы совпадение! Для пары int64 достаточно OR двух элементов.

Полные загрузки выполняются только при наличии полного вектора; остаток проверяется
обычным поиском. На amd64 проверка AVX2 предшествует созданию вектора и его операциям.

```sh
GOEXPERIMENT=simd go test ./04_archsimd
GOEXPERIMENT=simd go test ./04_archsimd -run='^$' -bench=BenchmarkContains -benchmem -count=5
go test ./04_archsimd  # fallback без эксперимента
```

В прежнем варианте build tags были закомментированы лишним `//`, а тесты были
привязаны к имени `_amd64_test.go`. Теперь проверки корректности общие для обеих
архитектур и fallback; измерения вынесены в настоящие `Benchmark...` без требований
к минимальному ускорению.
